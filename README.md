# C++ Programming

A personal learning repository for **C++ fundamentals, algorithms, problem solving, and small console projects**. The material is organized by learning level, with individual source files for lessons and exercises.

## Repository Structure

### C++ Fundamentals
- [Introduction to Programming Using C++ — Level 1](Intruduction%20Programming%20Using%20C%2B%2B%20-%20Level%201) — syntax, variables, data types, conditions, loops, functions, arrays, and basic structures.
- [Introduction to Programming Using C++ — Level 2](Intruduction%20Programming%20Using%20C%2B%2B%20-%20Level%202) — debugging, recursion, vectors, pointers, dynamic memory, file handling, and additional language features.

### Algorithms & Problem Solving
- [Level 1](Algorithms%20%26%20Problem-Solving%20Level%201) — introductory exercises covering conditions, loops, arithmetic, functions, and input validation.
- [Level 2](Algorithms%20%26%20Problem-Solving%20Level%202) — number problems, patterns, random values, and array operations.
- [Level 3](Algorithms%20%26%20Problem-Solving%20Level%203) — matrices, strings, and more problem-solving practice.

### Practice Projects
- [Projects](Projects) — console applications and exercises, including bank, ATM, student management, to-do list, math game, and rock-paper-scissors examples.

## How to Use

Browse a topic folder and open a `.cpp` file to study or run the example with a C++ compiler. Some projects consist of multiple source or header files; open the project folder to see its dependencies.

## Purpose

This is a **learning and practice archive**, not a single application. The goal is to develop programming fundamentals and improve problem-solving skills through gradual, hands-on exercises.
